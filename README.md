# 2026 경주여자중학교 3학년 과학 교실

경주여자중학교 3학년 과학 수업용 온라인 학습 포털입니다. `index.html`에서 단원(Ⅰ~Ⅶ)을 선택하면
해당 단원의 학습지 목록이 열리고, 학습지를 눌러 라이브 워크시트로 이동합니다.

현재는 「Ⅶ. 별과 우주」 배움활동 "시차 측정하기", "별의 밝기가 다른 까닭은", "별의 색이 다른 까닭은"이
등록되어 있으며, 다른 단원은 자료가 추가되는 대로 채워질 예정입니다.
학생이 웹에서 실험 결과와 정리하기 답을 입력·제출하면 Google 스프레드시트에 자동 저장되고,
교사가 확인 후 개별 피드백을 남길 수 있습니다.

## 파일 구성

- `index.html` — 과학 교실 포털 (단원 목록 → 학습지 목록)
- `worksheet.html` — 시차 측정하기 학생용 워크시트 (기본 실험 + 심화 실험 + 개념정리 + 문제풀이)
- `brightness.html` — 별의 밝기가 다른 까닭은 학생용 워크시트
- `starcolor.html` — 별의 색이 다른 까닭은 학생용 워크시트 (플랑크 복사 법칙 시뮬레이션 + H-R도 시뮬레이션)
- `galaxy.html` — 은하수와 우리은하 학생용 워크시트
- `seongdan-seongun.html` — 성단과 성운 학생용 워크시트 (우리은하 속 구상·산개 성단 분포 시뮬레이션 + 세 가지 성운 시뮬레이션 + 수소 원자 전자 들뜸 시뮬레이션, 자동 채점)
- `expansion.html` — 팽창하는 우주 학생용 워크시트 (고무풍선 가상 실험 + 도플러 효과 3D 시뮬레이션 + 풍선 우주·허블 법칙 연동 시뮬레이션, 자동 채점)
- `space-exploration.html` — 미래에 대한 도전, 우주 탐사 학생용 워크시트 (망원경 원리 시뮬레이션, 탐사선 카드, 인공위성 발사 게임, AI 조사 도우미). 사진·그림은 `images/space/`
- `Code.gs` — Google Apps Script 백엔드. **모든 워크시트가 이 스크립트 하나(배포 URL 하나)를 공유**하며,
  워크시트별로 같은 스프레드시트 안의 다른 시트(탭)에 저장됩니다
  (시차 → "답안", 밝기 → "밝기_답안", 별의 색 → "별색_답안").
  새 워크시트를 추가할 때 새로 배포하지 않고, `Code.gs`의 `FORMS` 객체에 항목만 추가하면 됩니다.

새 학습지를 추가하려면 `index.html`의 `UNITS` 배열에서 해당 단원의 `items`에
`{ title, desc, href }` 객체를 추가하면 됩니다.

## 배포 방법

### 1. 답안 저장소(Google Apps Script) 설정
1. 새 Google 스프레드시트 생성
2. [확장 프로그램] → [Apps Script] 열기
3. `Code.gs` 내용 전체 붙여넣기
4. [배포] → [새 배포] → 유형: **웹 앱**
   - 실행 계정: 나
   - 액세스 권한: 모든 사용자
5. 배포 후 나오는 웹 앱 URL 복사

### 2. 워크시트에 URL 연결
`worksheet.html`, `brightness.html`, `starcolor.html` 등 모든 워크시트 파일 안의 아래 줄을 찾아
**동일한** 방금 복사한 URL로 교체합니다 (모든 워크시트가 같은 URL 하나를 공유합니다).

```js
const APPS_SCRIPT_URL = "https://script.google.com/macros/s/여기에_배포된_웹앱_ID/exec";
```

### 3. 정적 페이지로 배포 (GitHub Pages)
저장소 Settings → Pages → Branch를 `main`(또는 배포용 브랜치), 폴더는 `/ (root)`로 설정하면
`https://<사용자명>.github.io/<저장소명>/` 주소로 포털(`index.html`)을 학생들에게 공유할 수 있습니다.

## 저작권 안내
`worksheet.html`의 시뮬레이션 iframe은 사이언스제이(sciencej.cafe24.com) 제작물을 임베드합니다.
배포 전 운영자의 임베드 사용 허락을 확인해 주세요.

## AI 조사 도우미 (Gemini 무료 등급) 설정
`space-exploration.html`의 "AI 조사 도우미"는 워크시트가 직접 Gemini를 부르지 않고, `Code.gs`(Apps Script)를 거쳐 호출합니다.
그래서 API 키가 공개 웹페이지에 드러나지 않습니다.
1. https://aistudio.google.com 에서 무료 API 키를 만듭니다.
2. Apps Script [프로젝트 설정] → [스크립트 속성]에 `GEMINI_API_KEY` = (키)를 추가합니다. (선택: `GEMINI_MODEL`, 기본값 `gemini-flash-latest`)
3. 최신 `Code.gs`를 붙여넣고 저장한 뒤, 편집기 위쪽 함수 목록에서 `testGemini`를 골라 **[실행]** → 권한 승인. 실행 로그에 "연결 성공"이 보이면 OK.
   (외부 서비스 호출 권한을 승인하지 않으면 AI뿐 아니라 모든 워크시트 제출이 막힐 수 있습니다.)
4. [배포] → [배포 관리] → 연필 → 새 버전으로 다시 배포합니다. (URL은 그대로)
학생 질문과 답변 요약은 스프레드시트의 "AI조사_기록" 시트에 남습니다. 학급 전체 요청은 분당 12회로 제한됩니다.
